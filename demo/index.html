chat-thread

One conversation component in seven apps: only the colors change. The switch repaints every thread in light or dark, or lets your system decide; the threads use theme: 'auto' and follow it with CSS only. Type in any box with a Send button: Enter sends, Shift+Enter breaks the line. Everything here is made-up data, and this page runs under a strict Content Security Policy.
